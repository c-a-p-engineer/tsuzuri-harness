This is what a saved Harness instance can look like.

Tsuzuri Harness stores identity, relationship, memory, acquired skills, and evolution as canonical state. Human-facing views such as CORE.md, JOURNEY.md, or a dashboard can present those facts without becoming the source of truth.

This page is a synthetic example. “Aoi” is not a bundled persona, not Tsuzuri, and not a real user's private instance. The sample exists only to demonstrate presentation.
