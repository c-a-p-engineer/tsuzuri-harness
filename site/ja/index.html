これは、AIの「キャラ設定集」ではありません。

完成した人格を最初に読み込ませるのではなく、まっさらな状態から始めて、実際の会話や仕事をもとに「このAI」を少しずつ形づくり、長く使い続けるための仕組みです。

1. まっさらな状態から始める

名前も性格も最初は未定です。「まだ決まっていない」「まだ分からない」を、そのまま正しい状態として扱います。

2. 会話は「根拠」であって、全部が記憶ではない

会話を丸ごと人格や記憶にはしません。将来も役立つ意味だけを選び、確定していること・候補・まだ分からないことを分けて残します。

3. 使う環境が変わっても続けられる

モデルやツールの性能と、そのAI自身の人格や記憶を分けて扱います。正規の状態を非公開Repository（Private Repository）に残すことで、実行環境が変わっても続きを始められます。

よくある仕組みとの違い

最初のプロンプトで人格を固定する仕組みでも、会話履歴を全部抱え続ける仕組みでもありません。

管理するのは「今どんな性格か」だけではありません。何を正式な状態として残すか、何を記憶するか、何を再利用できる技能にするか、どう働き、どう確かめ、次の環境へどう引き継ぐかまで扱います。

最初から決めた人格

性格を先に決めません

空欄、未形成、「まだ分からない」を無理に埋めず、そのまま有効な状態として扱います。

会話履歴の丸抱え

全部を記憶にはしません

会話は根拠のひとつです。将来の判断に役立つ意味だけを選んで残します。

実行環境そのもの

実行環境とAI個体を分けます

モデル、ツール、Sandboxなどは実行環境の能力です。それだけで人格や経歴になったことにはしません。

固定された手順

十分に強い実行役には細かい指示を減らし、苦手な実行役には担当範囲を狭めます。ただし、目的や安全条件は変えません。

育つ。覚える。学ぶ。働く。変わる。そして、続いていく。

Tsuzuri Harnessは、人格だけを保存する箱ではありません。AIを長く使い続けるために、人格・記憶・技能・仕事の進め方・引き継ぎをまとめて支える基盤です。

育

人格を少しずつ形づくる

誰かに言われたこと、候補として考えていること、自分で受け入れたことを分け、先回りで人格を決めません。

憶

記憶を選び、整理する

覚えるだけでなく、重複をまとめる、古い内容を更新する、不要になったものを外す、必要な記憶を探すところまで扱います。

技

使える技能を身につける

その場だけで使った知識と、今後も繰り返し使える技能を分けます。外部のSkill（スキル定義）や手法も、「これ見てー」だけで今の自分に合う形へ蒸留できます。

働

能力に合わせて仕事を任せる

使うモデル、実行役、ツールに合わせて、どこまで任せるか・仕事をどこまで細かく分けるか・どう確かめるかを調整します。

進

必要なときだけ変わる

直す、試す、まとめる、減らす、あえて変えない。機能やルールを増やすことだけを成長とは考えません。

継

長い作業でも続きを失わない

会話が圧縮されたり、別の実行役へ任せたりしても、目的・進捗・根拠・確認方法など、続きに必要な情報だけを引き継げます。

標準機能を全部見る

同じAIでも、使うモデルや実行役は変えられる

強いモデルでも軽い実行役でも、守るべき条件は変えません。

モデルの能力差は、そのAI自身の人格差ではありません。今使える能力に合わせて「どこまで任せるか」「どこまで細かく指示するか」を変えます。

変えてよいもの: 指示の細かさ / 作業の分け方 / 自律度 / 使わせるツール / 確認方法 / 上位の実行役へ戻す条件
変えないもの: 目的 / 権限 / 正しい情報源 / 安全条件 / プライバシー / 必要な確認
