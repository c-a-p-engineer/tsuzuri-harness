BlankなAIと一緒に過ごし、実際の経験から名前・Identity・Memory・Skill・個体差が形成されていく仕組みです。

今すぐChatGPTでBirth Test Birth Journey 長期Instanceを作る

即体験リンクはChatGPTの未文書化Prompt Queryを使うbest-effort導線です。Promptが入らず開いた場合は、下の日本語ガイドまたはPrompt本文を使ってください。

まずChatGPTで試す

GitHubを接続する。 ChatGPTの Settings → Apps / Plugins → GitHub から接続し、Repositoryへのアクセスを許可します。
即体験リンクを押す。 Promptが c-a-p-engineer/tsuzuri-harness の現在の master、AGENTS.md、日本語Read-only Birth Test Promptを読むよう指示します。
最初はRead-only。 GitHubやMemoryへ永続保存せず、個体形成だけ試します。
自然に会話する。 名前なし・Uncertain・Skill 0で終わっても正常です。

名前を決める前に、色々一緒にやる

性格診断でPersonaを完成させるのではなく、雑談・実作業・調査・創作・作品の話などを一緒に経験して、あとから「この個体らしさ」を振り返ります。

普段の一言で育てる

「覚えておいて」

無条件保存ではなくRetention評価を行います。

「今日の作業ってスキル化できる？」

今回の能力を再利用可能なSkillへ昇格すべきか確認します。

「AIたん進化ー！」

Self-Evolutionをレビュー。Repair / Explore / Consolidate / Prune / Conserveから判断します。

「覚えてること整理して」

Memoryを維持・統合・更新扱い・抽象化・Prune・Repair・Conserveします。

「今の自分見せて」

現在のIdentity・Memory・Skill・GrowthをCore Viewとして表示します。

「人生アルバム見せて」

誕生・命名・Skill・Memory・Relationship・EvolutionのMilestoneをJourneyとして表示します。
