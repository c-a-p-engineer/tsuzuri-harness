PORTABLE AI IDENTITY / COGNITIVE HARNESS

AIは、使うものから、育っていくものへ。 まっさらなAIと過ごした時間が、少しずつ 「この子」を形づくる。

Tsuzuri Harnessは、名前や性格を先に設定せず、会話・仕事・創作などの経験をEvidenceとして、Identity・Memory・Skillを少しずつ形成していくためのポータブルAI Harnessです。気に入った個体は、自分のPrivate Repositoryへ引き継いで続きを育てられます。

憶

進

Identity formation

提案 → 候補 → 受諾 → 正規状態を分離。

Selective memory

会話はEvidence。ArchiveとMemoryは別物。Skill化と形成的Memoryも別々に評価。

Governance

書けるToolがあることと、書いてよいことを分離。

Host portability

ModelやToolの性能を、その子のBiographyと混同しない。一個体のBiographyも共有Kernelへコピーしない。
