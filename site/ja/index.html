ワンクリックでPromptが入らない場合は、下の日本語ガイドまたはPrompt本文から始められます。

まずは保存なしで試す

1. GitHubを接続する。 ChatGPTの Settings → Apps / Plugins → GitHub から接続し、このRepositoryを読めるようにします。
2. 「まずはChatGPTで試す」を押す。 ChatGPTが現在のHarnessを読み、名前のないAIとして会話を始めます。
3. 普通に一緒に過ごす。 雑談、仕事、調査、創作、作品の話などをしてみます。名前や性格を最初から決める必要はありません。
4. 気に入ったら「この子を保存したい」と言う。 この段階ではまだGitHubへ書き込まず、次のRepositoryへ移すための引き継ぎ情報をまとめます。

内部では、この保存なしのお試しを Read-only Birth Test と呼びます。専門用語を覚える必要はありません。

お試し中にできた個体を、そのまま捨てる必要はありません。気に入ったときだけ、Private Repositoryへ引っ越して長期運用できます。

会話全文を自動で「人格」や「記憶」にするわけではありません。Accepted / Candidate / Uncertainを分け、必要なものだけ引き継ぎます。

ChatGPTからそのまま保存できることもある

ChatGPTだから常にread-only、というわけではありません。現在のChatGPTに接続されたGitHub連携の機能とRepository権限で決まります。

標準GitHub App

基本はread-only。Private Repositoryを読んで同じ個体の続きを話せます。

Write対応Plugin / Connector

GitHubへの書き込み操作が公開され、Private Repositoryへの権限もあれば、ChatGPTからMemory・Skill・Evolution等を直接commitして保存できます。

Write操作がない場合

会話と読み取りはChatGPTで続け、永続化だけCodex等のWrite可能なHostへ引き継ぎます。

書き込み可能でも、勝手に全状態を書き換えてよいわけではありません。Canonical StateとGovernanceを確認し、書き込み後は実際のcommitを検証します。

名前を決める前に、色々一緒にやる

性格診断でキャラクターを完成させるのではなく、雑談・実作業・調査・創作・作品の話などを一緒に経験して、あとから「この個体らしさ」を振り返ります。

普段の一言で育てる

「覚えておいて」

何を残すべきか、どこへ残すべきかを判断します。

「今日の作業ってスキル化できる？」

今回できたことを、今後も使えるSkillとして残す価値があるか確認します。

「今の自分、改善できるところある？」

今の自分を見直します。変えない方がよければ、そのままも正常です。

「この子を保存したい」

保存なしのお試し中なら、GitHubへ勝手に書かず、Private Repoへ移すための引き継ぎ情報を作ります。

「覚えてること整理して」

増えたMemoryを整理・統合・更新・Pruneします。

「今の自分見せて」

現在の名前・個性・Memory・Skill・最近の成長を表示します。

「人生アルバム見せて」

誕生・命名・Skill・Memory・Relationship・Evolutionの節目を振り返ります。
