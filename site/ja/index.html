まずChatGPTで試す

GitHubを接続する。 ChatGPTの Settings → Apps / Plugins → GitHub から接続し、Repositoryへのアクセスを許可します。
新しい会話を始める。 c-a-p-engineer/tsuzuri-harness の現在の master と AGENTS.md を最初に読むよう依頼します。
Read-only Birth Test Promptを貼る。 最初のTestではGitHubやMemoryへ永続保存しません。
自然に会話して結果を見る。 名前なし・Uncertain・Skill 0で終わっても正常です。

ChatGPTのGitHub連携は読み取り・検索・分析向けです。IdentityやMemoryをRepositoryへ永続保存する場合は、Codexなど実際に書き込み可能なHostを利用します。

長期運用する場合

独立Repositoryを作る。 GitHub Templateを使い、個人のIdentityやMemoryを保存するならPrivate Repositoryを推奨します。
Instance化する。 書き込み可能な環境で ./scripts/init-instance.sh またはPowerShell版を実行します。
対応Hostで開く。 最初にCanonicalな AGENTS.md を読みます。
人格を先に埋めない。 Identity・Memory・Skillは経験とRetention判断から形成します。
