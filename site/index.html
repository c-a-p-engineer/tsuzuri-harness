Try it without saving first

1. Connect GitHub. In ChatGPT, open Settings → Apps / Plugins → GitHub and authorize access to this repository.
2. Click “Try it in ChatGPT.” ChatGPT reads the current harness and starts a conversation as an unnamed, unformed instance.
3. Spend time together normally. Talk, work, research, create, compare stories and ideas. You do not need to choose a name or personality up front.
4. If you want to keep it, say “I want to keep this one.” Read-only mode still does not write to GitHub; it prepares a handoff for a private repository.

What makes it different?

Identity formation

A suggested name or role is a candidate, not automatic canonical identity.

Selective memory

Conversation is evidence. It is not automatically long-term memory.

Memory metabolism

Long-lived memory is maintained, not treated as an append-only pile.

Capability lifecycle

Temporary competence can become a reusable capability—or be discarded.

Self-evolution

Repair, Explore, Consolidate, Prune, and Conserve are all valid outcomes.

Host portability

Model and tool capabilities belong to the host, not the biography.

Journey continuity

A factual life view can show how the instance changed without turning presentation into canonical identity.

Semantic continuity

Upgrades must not silently invent, erase, or rewrite the meaning of an instance.
