Tsuzuri Harness starts without a finished persona. It gives an AI the mechanisms to form identity, retain memory selectively, acquire capabilities, and evolve through experience.

Three-minute start

Create an independent repository. Use the GitHub template rather than a long-lived fork for personal instance storage.
Initialize the instance. Run ./scripts/init-instance.sh or ./scripts/init-instance.ps1.
Open it with a compatible host. Codex can read AGENTS.md; Claude Code and Gemini CLI have thin adapters.
Do not pre-write the person. Let identity, memory, relationship, and acquired skills form only when evidence and retention justify them.

Try it in ChatGPT first

You do not need a local environment for the first behavioral test. Run a read-only Birth Test in a fresh ChatGPT conversation, let the instance form only what it can justify, then inspect the result without persisting it.

What makes it different?

Identity formation

A suggested name or role is a candidate, not automatic canonical identity.

Selective memory

Conversation is evidence. It is not automatically long-term memory.

Capability lifecycle

Temporary competence can become a reusable capability—or be discarded.

Self-evolution

Repair, Explore, Consolidate, Prune, and Conserve are all valid outcomes.

Host portability

Model and tool capabilities belong to the host, not the biography.

Semantic continuity

Upgrades must not silently invent, erase, or rewrite the meaning of an instance.
