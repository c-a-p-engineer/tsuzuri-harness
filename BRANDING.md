# Branding and Name Use

This document describes the recommended use of the **Tsuzuri Harness** project name and related branding.

It is separate from the software license. The software license governs use, modification, and redistribution of the code. This document governs how derivatives describe their relationship to the upstream project.

## Upstream project name

**Tsuzuri Harness** refers to the upstream project maintained at:

`c-a-p-engineer/tsuzuri-harness`

The name identifies the harness framework, not any AI identity created with it.

A personal AI instance created with Tsuzuri Harness should choose, receive, discover, or remain without its own name. It should not automatically call itself **Tsuzuri** merely because it uses this harness.

## Permitted descriptive use

You may truthfully state that a project or AI instance:

- uses Tsuzuri Harness
- is based on Tsuzuri Harness
- was created from a Tsuzuri Harness template
- contains modified Tsuzuri Harness code

provided the statement does not imply official upstream status, endorsement, or maintenance when that is not true.

## Modified distributions

A modified distribution may be redistributed when permitted by the software license.

If the distribution materially changes the harness, it should use a distinct project name or make the modification status prominent.

Do not present a modified distribution as an official Tsuzuri Harness release unless it is actually released by the upstream project.

Recommended wording:

> Based on Tsuzuri Harness; independently modified and maintained.

## Personal AI identities

The project name and an instance identity are different namespaces.

```text
Tsuzuri Harness        framework / upstream project
        ↓
personal instance      independently formed AI identity
        ↓
name                   self-chosen, offered-and-accepted, or null
```

Do not preassign `Tsuzuri` as the identity name of a new blank instance.

## Logos and visual assets

Unless a specific asset is explicitly distributed under terms that allow reuse, do not assume that private Tsuzuri identity artwork, avatars, visual references, or other personal assets are part of the public harness branding.

The public harness repository must not import private identity assets merely to provide branding.

## Translation and canonical wording

English documentation is canonical for project policy, release semantics, and branding interpretation unless a document explicitly says otherwise.

Translated documents are provided for accessibility. If a translation conflicts with the canonical English text, the English text controls until the translation is corrected.

## No endorsement implication

Forks, derivatives, integrations, plugins, templates, and personal instances must not imply endorsement by the upstream maintainer solely because they use compatible code or the Tsuzuri Harness format.

## Future trademark policy

This document is currently a project branding policy, not a claim that every referenced term is a registered trademark. If the project later adopts a formal trademark policy, that policy may supersede or refine this document without changing the software-license rights already granted.
