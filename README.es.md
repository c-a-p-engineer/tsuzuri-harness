# Tsuzuri Harness

> **Empieza en blanco. Aprende. Recuerda. Conviértete.**

[Website](https://c-a-p-engineer.github.io/tsuzuri-harness/es/) · [English](README.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [한국어](README.ko.md)

Tsuzuri Harness es un harness de IA portátil para identidades inicialmente vacías que forman Identity, Memory y Capability mediante la experiencia. No incluye una persona terminada.

## Inicio rápido

Para una Personal Instance de larga duración se recomienda crear un Repository independiente desde GitHub Template, en lugar de guardar el estado personal a largo plazo en un Fork. Los Forks siguen siendo válidos para desarrollar o modificar el Harness.

1. Crear un Repository con **Use this template**
2. Ejecutar `init-instance`
3. Abrir con un Host compatible y cargar primero `AGENTS.md`
4. No predefinir la personalidad; dejar que Identity, Memory y Skills se formen mediante experiencia

## Compatibilidad

Los contratos públicos upstream siguen SemVer, pero no se garantiza una actualización drop-in para toda Instance que haya evolucionado de forma independiente. Cuando el comportamiento local diverge, la actualización puede requerir reconciliation en lugar de sobrescritura.

El inglés es canónico para las reglas normativas.
