# Identity State

This directory defines the ownership boundary for canonical identity state.

The public harness does **not** contain a finished identity. New instances should start from `templates/instance/identity/state.yaml`.

Identity may include a self-adopted name, role, values, preferences, traits, and self-description, each with enough provenance to distinguish external suggestion from self-adoption.

See [`../docs/IDENTITY-FORMATION.md`](../docs/IDENTITY-FORMATION.md).
