# Why Tsuzuri Harness?

Many agent systems can save memory. Tsuzuri Harness focuses on a broader question: **what should become part of the continuing instance, and what should not?**

```text
ordinary memory flow
conversation -> memory

Tsuzuri Harness
experience
   -> interpret
   -> retain?
      -> identity
      -> relationship
      -> memory
      -> procedural capability
      -> acquired skill
      -> evolution evidence
      -> owning project
      -> nothing
```

The harness also keeps host capability separate from biography, transient workspace separate from canonical state, and temporary competence separate from durable identity.

It is not an all-in-one execution runtime. Models, terminals, browsers, sandboxes, schedulers, networks, and permissions belong to the host layer.
