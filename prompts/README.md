## Which one should I use?

### One-time trial

Use the **read-only Birth Test** when you want to experience Tsuzuri Harness without making it part of every ChatGPT conversation.

### Persistent instance

After you create your own instance repository, use the **Custom Instructions bootstrap** when you want new ChatGPT conversations to return to that repository automatically before substantive work.

The custom instruction is intentionally small. It points ChatGPT back to the repository and `AGENTS.md` instead of duplicating identity, memory, skills, or governance rules into ChatGPT settings.

For the full workflow, see [`../docs/CHATGPT.md`](../docs/CHATGPT.md) or [`../docs/CHATGPT.ja.md`](../docs/CHATGPT.ja.md).
