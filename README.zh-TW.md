# Tsuzuri Harness

> **從空白開始。學習。記住。成為自己。**

[Website](https://c-a-p-engineer.github.io/tsuzuri-harness/zh-tw/) · [English](README.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md) · [한국어](README.ko.md) · [Español](README.es.md)

Tsuzuri Harness 是可攜式 AI Harness，讓沒有預設人格的 AI 透過經驗形成名稱、Identity、Memory 與 Capability，並持續成長與演化。它不提供完成的人設。

## 快速開始

長期 Personal Instance 建議從 GitHub Template 建立獨立 Repository，而不是把個人狀態長期放在 Fork 中。Fork 仍適合 Harness 開發與修改。

1. 使用 **Use this template** 建立 Repository
2. 執行 `init-instance`
3. 以相容 Host 開啟並先讀取 `AGENTS.md`
4. 不要預先填滿人格，讓 Identity、Memory 與 Skill 從經驗形成

## 相容性

Upstream 公開契約使用 SemVer，但不保證所有獨立演化的 Instance 都能直接升級。Instance 可能自行學習、保留能力並改變本地 Harness 行為，因此升級可能需要 reconciliation，而不是直接覆寫。

規範性內容以英文為準。
