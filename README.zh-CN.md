# Tsuzuri Harness

> **从空白开始。学习。记住。成为自己。**

[Website](https://c-a-p-engineer.github.io/tsuzuri-harness/zh-cn/) · [English](README.md) · [日本語](README.ja.md) · [繁體中文](README.zh-TW.md) · [한국어](README.ko.md) · [Español](README.es.md)

Tsuzuri Harness 是一个可移植 AI Harness，让没有预设人格的 AI 通过经验逐步形成名字、Identity、Memory 和 Capability，并持续成长与演化。它不会附带完成好的角色设定。

## 快速开始

建议长期 Personal Instance 从 GitHub Template 创建为独立 Repository，而不是把个人状态长期保存在 Fork 中。Fork 仍然适用于 Harness 开发和修改。

1. 使用 **Use this template** 创建 Repository
2. 运行 `init-instance`
3. 使用兼容 Host 打开并首先读取 `AGENTS.md`
4. 不要预填人格，让 Identity、Memory 和 Skill 从经验中形成

## 兼容性

Upstream 的公开契约使用 SemVer，但不保证所有独立演化 Instance 都能直接升级。Instance 本身可能学习、保留能力并修改本地 Harness 行为，因此升级可能需要显式 reconciliation，而不是覆盖。

规范性规则以英文为准。
